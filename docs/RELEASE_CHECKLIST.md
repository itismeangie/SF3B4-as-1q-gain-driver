## Technical Checks

Run from repository root:

```bash
bash -n 0*/run.sh 04_netbid2_driver_prioritization/run_sjaracne_networks.sh
Rscript -e 'files <- Sys.glob("0*/*.R"); for (f in files) parse(file=f); cat(length(files), "R files parsed\n")'
python3 -m py_compile $(find . -type f -name '*.py' -print)
python3 docs/check_rerun_readiness.py --write docs/rerun_path_audit.tsv
rg -n "ggplot|ggsave|plot\\(|pdf\\(|png\\(|savefig|matplotlib|ComplexHeatmap|draw\\.NetBID" --glob "*.R" --glob "*.py" .
```

Then remove local caches generated by checks:

```bash
find . -type d -name __pycache__ -prune -exec rm -rf {} +
find . -name ".DS_Store" -delete
```
